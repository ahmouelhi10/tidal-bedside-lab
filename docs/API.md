# HTTP API

All responses are JSON. Errors: `{ "error": "..." }`.

| Method & path | Auth | Purpose |
|---|---|---|
| `GET /api/health` | - | `{status, version, uptimeS, scenarios, node}` |
| `GET /api/scenarios` | - | Scenario list (id, title, difficulty, durationS, kind, summary, spec, learning). Scoring criteria are never sent to the client |
| `POST /api/sessions` | - | Body `{scenario?, spec?:{sex,age,heightCm,weightKg}, learner?}`. Ranges: age 18-100, height 140-210 cm, weight 35-250 kg, BMI 15-65. Returns `{id, seed, spec, ...}`; the **server issues the seed** |
| `GET /api/sessions/:id` | - | Public view (status, result if submitted) |
| `POST /api/sessions/:id/submit` | - | Body `{log:[{t,type,...}], until, hash}`. The server validates the log (event types, monotonic time, size limits), replays it in a worker, compares the hash and stores its own score. One submission per session (409 otherwise) |
| `GET /api/sessions` | Bearer `API_TOKEN` | Instructor list. `GET /api/sessions/:id?log=1` adds the event log |
| `POST /api/sessions/:id/self` | - | Body `{pct: 0-100, ants?: {task, team, sa, dm: 1-4}}`. The learner's self-assessment, accepted once and only after submission (409 otherwise) |
| `GET /api/research/export` | Bearer `API_TOKEN` | De-identified CSV (or `?format=json`) of every submitted session: salted learner pseudonym, verified score and grade, each criterion, key action times, instructor changes, team orders, self-assessment. See `docs/VALIDITY_STUDY.md` |
| `POST /api/live/:id/open` | - | Opens the live channel of an open session; returns `{code, watchers}` (6-character join code) |
| `GET /api/live/:id/stream` | - | Server-Sent Events for the learner: `watchers {watchers}`, `cmd {seq, what, ...}` |
| `POST /api/live/:id/state` | - | Learner's state summary (≤ 8 KB, at most every 0.4 s), relayed to instructors |
| `GET /api/live/join/:code` | join code | Server-Sent Events for an instructor: `hello {scenario, learner, spec, learnerOnline}`, `state`, `learner {online}`, `sent` |
| `POST /api/live/join/:code/cmd` | join code | Body `{what, mlPerMin?, side?, text?}` with `what` in `INJECTS`. Relayed to the learner, whose client logs it as `instructor.inject`; returns `{ok, seq, delivered}` |

Event types are listed in `EVENT_TYPES` (`src/engine/patient.js`), including the tracheal-tube and bronchoscopy events `airway.intubate {depthCm?}`, `airway.tube_adjust {cm}`, `bronch.insert`, `bronch.suction {where: trachea|R|L}` and `bronch.remove`, and the infectiology ward events `ward.advance {hours: 1-72}`, `ward.sample {kind: blood|urine|sputum|uag}`, `ward.rx.start {drug, route: iv|po, dose?: std|high}`, `ward.rx.stop {drug}` and `ward.order {what: labs|lactate|fluids30|remove_line|tte|renal_us|cxr}` (the ward has its own clock in hours, advanced only by `ward.advance`), and the laboratory event `lab.order {kind: abg|lactate|chem|cbc|coag}`, the live instructor event `instructor.inject {what: vf|pea|asystole|svt|af|bleed|bleed_stop|tension_ptx|hyperkalaemia|airway_obstruction|anaphylaxis|bronchospasm|mh|hypoglycaemia|avblock3|brady|torsades|flutter|avblock1|avblock2|wenckebach|lbbb|rbbb|bbb_off|seizure|ecg_wpw|ecg_lvh|ecg_lahb|ecg_nstemi|ecg_pericarditis|ecg_wellens|ecg_bigeminy|ecg_clear|ponv|high_spinal|marker, mlPerMin?, side?, text?}` (`flutter`, `avblock1`, `avblock2` set those rhythms; `torsades` starts torsades de pointes on a long-QT substrate so it can recur; `isoprenaline` is given with `drug.infusion` in mcg/min), the team-mode events `team.order {id, act}` (act is a drug, fluid, blood, bicarbonate, lab or shock event; the result carries the member's read-back), `team.correct {id}` and `team.confirm {id}` (the client then dispatches the read-back action), blood products `blood.transfuse {kind: prbc|whole|ffp|platelets|cryo}`, `drug.bolus {route?: iv|im|regional}` (IM for epinephrine, regional for bupivacaine and lidocaine), `io.access`, `pacing.set {on, rate?: 30-180, mA?: 0-200}` (needs pads), `procedure.arterial_line {us?}`, `procedure.central_line {site: ijv|scv|fem, us?}`, `procedure.ng_tube`, `procedure.urinary_catheter`, `exam.ecg12`, `vaporizer.set {agent?: sevoflurane|isoflurane|desflurane, percent: 0-8|0-5|0-18}`, `n2o.set {percent: 0-70}`, `niv.set {mode: off|cpap|bipap|hfno, fio2?, epap?: 0-20, ipap?: 0-30, flow?: 0-70}` (spontaneous breathing only), `drug.infusion {drug: insulin, rate: U/min}` and `{drug: glucose, rate: g/min}` (fixed-rate insulin and glucose 10 %), `drug.bolus {drug: midazolam, route: im}`, lab kinds `ketones` and `cbg` (capillary ketones and glucose, 1 min), `procedure.vagal {technique?: modified|standard}`, `fluid.bolus {fluid?: balanced|saline|saline3|glucose5}` (3 % saline at most 500 mL a bolus; sodium follows the fluids), `procedure.endoscopy` (band ligation of bleeding varices), `neuraxial.spinal {amount: 2-25 mg hyperbaric bupivacaine 0.5 %}`, `neuraxial.epidural {action: test|topup, volumeMl?: 1-25}` (what happens depends on where the catheter really lies: `spec.catheter` epidural|intrathecal|intravascular), `neuraxial.assess` (returns the sensory level and the Bromage score). Calcium (`calciumChloride`, `calciumGluconate`): `amount` is mmol of elemental calcium, at most 30 per bolus (delivered through the ventilator or bag, a supraglottic airway, a tube, or a sealed face mask), and the lab kinds `cardiac` (hs-troponin T, NT-proBNP, D-dimer) and `renal` (creatinine, urea) (the sample freezes the values at that time; `Patient.labResults()` releases each result after its turnaround: 3 min for the blood gas (with Na+, K+, ionised Ca2+, glucose) and lactate, 45 min for the chemistry panel and the blood count); each event's nested payload is validated by the engine (`validateEventShape`), and a rejected event is still logged so a replay rejects it identically. `equipment.remove {items: [ivAccess | ecgLeads | spo2Probe | nibp | capnography | tempProbe | padsOn | o2]}` takes equipment off the patient; skills training logs it at the start so the learner places that equipment.
